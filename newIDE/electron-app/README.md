# GDevelop IDE Electron app

This is the Electron sources to package GDevelop new IDE into a standalone editor.

See [the general README](../README.md) for more information.

Project-owned desktop services can exchange IPC requests with the game in a
local Electron export or standalone Electron preview. See the
[desktop service IPC guide](../app/resources/gd-project-template/docs/DESKTOP_SERVICE_IPC.md)
for configuration, message formats, and examples.
