# Runtime assets

Store game images, models, fonts and audio here. Register runtime files in the root `resources.settings` before referencing them from game source. Add category directories such as `models/`, `audio/`, `ui/` or `environment/` as needed.

Editable production files belong in `sources/`; TSL material source belongs in `materials/` when used. Accompanying asset manifests and license notices may stay beside their runtime exports. Record their path conventions and provenance in [docs/ASSET_SOURCES.md](../docs/ASSET_SOURCES.md).

Preserve existing registered paths during documentation or directory cleanup.
