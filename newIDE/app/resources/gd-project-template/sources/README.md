# Editable production sources

Store editable model, image and audio production files here, using categories when useful, such as `models/` or `environment/`. Export game-ready resources to `assets/` and document the relationship in [tools/README.md](../tools/README.md).

These files are versioned production inputs, not disposable caches. Keep external dependencies inside the project or pack them where supported. Check relative texture and library references when moving Blender files. Preserve source and license information in [docs/ASSET_SOURCES.md](../docs/ASSET_SOURCES.md).
