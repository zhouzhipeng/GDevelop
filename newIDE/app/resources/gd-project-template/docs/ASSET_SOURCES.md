# Asset provenance

No game-specific assets are supplied by this template. Record imported and generated resources as they are added; do not infer a license from an absent notice.

For each asset or coherent asset group, record:

- Runtime path relative to the project root.
- Original author, source URL or generation method.
- License and local license-notice path, where applicable.
- Editable file under `sources/` or producing tool under `tools/`.
- Relevant modifications and regeneration instructions.

Keep original license notices with the corresponding resources. This index describes provenance; it does not grant additional rights.
