## 本轮发现并修复的问题

1. **验证工具改变了正在使用的扩展元数据。** 入门版在执行 validate_project_files 前正常运行，执行后预览缺少 SmoothCamera、移动映射等自定义行为；完整版在同一路径下出现函数缺失异常。原恢复逻辑使用校验用的空代码写入器重建元数据，丢失了真实脚本路径和依赖。现在恢复加载器保留的完整元数据快照；每个已加载扩展最多保留一份快照，替换或卸载时显式释放。新增正常校验、校验抛错、快照替换与卸载释放测试。
2. **有效但 deprecated 的效果参数未进入序列化 schema。** frustumSize 仍在方向光元数据中声明，应保留其值。新增机器使用的 serializedParameters，与公开编辑属性分离；Settings catalog 升至版本 7，旧生成缓存自动重建，本地作者语法版本仍为 8。
3. **根据整数默认值误推断整数限制。** tileScale 的默认值是 1，但有效配置可以是 0.2。原生 JSON 数字样本现在生成 number schema；明确声明的整数字段仍按其既有 schema 校验。

3D 官方原始模板已加入离线常规测试，未预先清理效果参数或修改小数值来规避失败。
